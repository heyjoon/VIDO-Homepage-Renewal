# VIDO Redesign Product Goals

## North Star

VIDO should become the place where media artists upload, manage, exhibit, and reuse their artworks for contests and opportunities.

The homepage renewal should not be only a visual refresh. It should create a product loop:

```txt
Homepage visit
-> artwork upload
-> artwork library
-> contest submission
-> mypage tracking
-> repeat participation
```

## Primary Goals

1. Make artwork upload the clearest action on the homepage.
2. Explain why uploading to VIDO matters.
3. Connect uploaded artworks to Awards/Contest submission.
4. Make My Page feel useful after upload.
5. Prepare admin workflows for reviewing artworks, contests, and submissions.

## Audiences

### Media Artists

Needs:

- upload artwork
- understand artwork status
- submit work to contests
- track submission result
- keep portfolio organized

### Collectors / Viewers

Needs:

- understand VIDO as a media-art platform
- browse curated media artwork
- trust the platform's legitimacy

### Admins

Needs:

- review uploaded artworks
- manage contest content
- review contest submissions
- track operational status

## Page Groups

### Public

- Home
- Media Art / Gallery
- Author / Artist info
- Collector info
- Awards / Contest home
- Contest detail

### User

- Login / Signup
- My Page Dashboard
- My Artworks
- Artwork Upload / Edit
- Contest Submissions
- Profile / Account

### Admin

- Admin Dashboard
- Artwork Review
- Contest Management
- Submission Review
- User Management
- Content Settings

## Success Criteria

- A new visitor understands within one screen that VIDO is for media-art upload and reuse.
- A logged-in artist can see what to do next after uploading artwork.
- A READY artwork can be submitted to an OPEN contest without re-uploading the same media file.
- My Page shows both artwork state and contest submission state.
- Admin pages use clear tables, filters, status labels, and review actions.
